# Find Your Supplement — site repo

**This repository is PUBLIC, and every file on `gh-pages` is served verbatim
at findyoursupplement.co (including dot-folders — `.nojekyll` is set).**
Anyone can read every branch, every commit message and the full history.

Never put anything confidential or proprietary here: internal notes,
process docs, to-do lists, skills, prompts, IDs, credentials, business
plans, or anything the user would not want a competitor or customer to
read. Only the published website belongs in this repo. Keep working notes
in the private `find-your-supplement` app repo or on the user's machine.

The `main` branch still carries the old Next.js source and a deploy
workflow that rebuilds `gh-pages` from it — never push to `main`.
